## Local changes

1. Root `scopeName`s are prefixed with `odoo.`, so the grammars don't collide when Owl Vision is co-installed. Inner token scopes are unchanged.
2. `owl.template.json` adds the `owl-attributes-generic` rule, included from `component-tags`, `html-tags` and `t-tag`. It gives unrecognised `t-*` attributes a single scope; without it an attribute like `t-custom-foo` is split between an unmatched `t-` and a `custom-foo` picked up by `html-attributes`.
